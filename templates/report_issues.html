Report a Bug or Issue

We're committed to providing a reliable and high-quality service. If you encounter any bugs, technical issues, or problems with your alerts, please let us know so we can fix them quickly.

How to Report Issues:

To report a technical issue, please email us at support@auctionalertsarchive.com with the following information:

Please Include:
  • A clear description of the issue you encountered
  • Steps to reproduce the problem (if applicable)
  • Your browser and device information
  • Any error messages you received
  • Screenshots or screen recordings (if helpful)
  • The approximate time the issue occurred
Issue Priority
Priority Response Time Examples
Critical 2-4 hours Service down, data loss, security issues
High 4-8 hours Major feature broken, significant functionality impaired
Medium 1-2 days Minor feature issue, workaround available
Low 2-5 days UI/UX improvements, cosmetic issues

Thank you for helping us improve Georgia Auction Alert Archive!
